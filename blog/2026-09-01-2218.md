# 月曜始まりの月間カレンダーを、Pages で出せるところまで

2026年9月1日夜。前回はリポジトリの地図を README に書いたところで止まっていた。今回は「まず月間カレンダー」という依頼で、見た目と公開の土台を作り直した。

## 決めてから書いた

実装の前に ADR-0001 を置いた。週の始まりは月曜日、表示は対象月を含む 6 週間、祝日は YAML、色は CSS 変数、公開は GitHub Actions で `dist/` を Pages に載せる。プロトタイプの日曜始まり JSONL 祝日は、この方針と噛み合っていなかった。

## 2026年8月で確かめた

仕様の例が具体的だったので、そこをそのまま確認した。2026年8月は 7月27日（月）から 9月6日（日）までの 42 マス。土曜は薄い青、日曜と祝日は薄い赤。8月11日には YAML から読んだ「山の日」が出る。

ローカルは `http://127.0.0.1:5173/tech-calendar/`。GitHub Pages と同じ `/tech-calendar/` 配下で動かしている。CI の build ジョブも通過した。

```
4b9a860 Add Monday-start monthly calendar with YAML holidays and Pages deploy.
```

PR は https://github.com/windhole/tech-calendar/pull/1

## まだ残っていること

マージしないと本番の Pages は更新されない。イベントデータは JSONL のままで、登録 UI もバックエンドもない。カレンダーの色を変えたいときは `src/calendar/monthly-calendar.css` の先頭の変数を触れば足りる、というところまでが今回の範囲だった。
