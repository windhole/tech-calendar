# bun に寄せた

見た目の確認方法を聞かれた直後、「そういえば bun でやりたい」と来た。パッケージマネージャだけの話なので、カレンダーの仕様には触らず、手元と CI の手順を揃えた。

ADR-0002 に決めた。ロックは `bun.lock`、`package-lock.json` は捨てる。GitHub Actions は Node の `npm ci` をやめて `oven-sh/setup-bun`（1.4.0）と `bun install --frozen-lockfile` にした。README の起動も `bun run dev` になった。

```bash
bun install
bun run dev
```

確認 URL はこれまでどおり http://localhost:5173/tech-calendar/ 。見た目の中身は変わっていない。変わったのは、依存を入れる道具だけだ。
