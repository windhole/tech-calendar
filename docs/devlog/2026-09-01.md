## 22:00 〜 月曜始まりの月間カレンダーと GitHub Pages

### やったこと
- 月間カレンダーを `src/calendar/` に切り出し、対象月を含む 6 週間・月曜始まりにした（2026年8月は 7/27〜9/6）
- 祝日を `data/holidays.yaml` に移し、ビルド時に `js-yaml` で読み込む
- 見た目は `monthly-calendar.css` の CSS 変数と BEM 風クラスに集約（土=薄青、日・祝=薄赤）
- GitHub Actions で `dist/` を GitHub Pages に載せる workflow を追加。Vite `base` は `/tech-calendar/`

### 詰まった点・気づき
- `js-yaml` 5 は default export がなく、`load` の named import が必要だった
- 既存の ESLint エラーは shadcn の `src/components/ui/` 側で、今回の変更とは無関係
