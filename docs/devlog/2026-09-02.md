## 22:40 〜 CSV から events.yaml を生成する

### やったこと
- `csv2yaml.rb` を追加。`data/` の最新 CSV の TRUE 行だけを `public/events.yaml` と同じリスト形式に変換する
- 日付は「9月5日(土)」をファイル名の西暦付き `YYYY-MM-DD` にする。`tag` は値があるときだけ出す
- `make events` で実行できるようにした。出力は `data/events_YYYYMMDD-HHMM.yaml`

### 詰まった点・気づき
- Ruby 2.6 の `String#dump` は日本語を `\u` エスケープするので、クォートは自前にした
