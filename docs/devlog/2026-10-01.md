## 20:28 〜 make が rbenv の Ruby 4.0.7 を使う

### やったこと
- `make events` がシステム Ruby 2.6.10 の `filter_map` 不足で落ちていたので、実行 Ruby を rbenv の最新安定版にした
- ADR-0020 を書き、`.ruby-version` を 4.0.7 にした。Makefile は `rbenv exec ruby` を呼ぶ
- 未導入だった 4.0.7 を `rbenv install` した
- `make events` と `make check` が Ruby 4.0.7 で完走することを確認した

### 詰まった点・気づき
- rbenv には 3.4.7 までしか入っておらず、一覧上の最新安定版は 4.0.7 だった
- シェルの PATH に rbenv の shims が無いので、素の `ruby` は今も `/usr/bin/ruby` になる。make 側で `rbenv exec` する
- 変換が通ったあと、より新しい `2026 (1).csv` から `public/events_2026.yaml` を書き直した。以前重複で止まっていた `2026.csv` はスキップされる
