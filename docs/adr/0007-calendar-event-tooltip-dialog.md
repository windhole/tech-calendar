# 0007. カレンダー上のイベントはツールチップとダイアログで見る

Date: 2026-09-03
Status: Accepted

## Context

月間カレンダーのセルは狭いのでイベント名が省略される。全文を確認したり、日付・会場・URL を見たりするには、セルから一覧まで視線を移す必要がある。ホバーとクリックでセル上から辿れるようにする。

## Decision

- ホバー（およびキーボードフォーカス）では、既存の Radix Tooltip で `eventName` の全文を出す。
- クリックでは Popover ではなく Dialog を出す。詳細を読んでいる途中でポインタがセルを外れても閉じないようにする。
- Dialog にはイベント名、開催日、会場、URL を置く。URL は `target="_blank"` で別ウィンドウ（タブ）を開く。
- セル内チップの見た目はこれまでどおり `monthly-calendar.css` に置き、オーバーレイだけ shadcn の Tooltip / Dialog を使う。

## Consequences

- カレンダー操作はセル上で完結する。一覧は期間の俯瞰用のまま残る。
- Tooltip と Dialog を同じボタンに付けるため、入れ子の Trigger は使わず、Dialog は開閉状態で制御する。
- タッチ端末ではホバーが使えないので、全文は Dialog 側でも確認できる。
