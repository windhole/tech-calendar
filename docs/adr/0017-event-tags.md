# 0017. イベントに複数タグを付けて OR で絞り込む

Date: 2026-09-06
Status: Superseded by [ADR-0018](0018-event-region.md)
Amends: [0005](0005-events-yaml.md), [0006](0006-csv2yaml.md)

## Context

カレンダー表示とリスト表示で、イベントの種類やテーマで見たいものだけに絞りたい。CSV には以前から `tag` 列があり、csv2yaml は単一文字列として YAML に残していたが、アプリは読んでいなかった。1 イベントが複数の分類を持つことがある。

## Decision

- `Event` は任意の `tags: string[]` を持つ。無いときは空配列。語彙はアプリに固定せず、読み込んだデータから集める。
- YAML は `tags` 配列。csv2yaml は CSV の `tag` 列を `,` と `、` で分割して出す。列名は変えない。空ならキー自体を出さない。
- パーサは現行の `tags` 配列に加え、古い `tag: 文字列` も 1 タグとして読む。
- 絞り込みは複数選択の OR。未選択なら全件。未分類は、タグを何も選んでいないときだけ見える。
- 選択は URL の繰り返しパラメータ `?tag=` に載せ、カレンダーとリストの切替でも残す。

## Consequences

- スプレッドシートの `tag` を埋めて `make events` すれば、デプロイ後にチップが出る。
- AND 絞り込み、未分類専用チップ、タグごとのカレンダー色は持たない。
- タグなしの既存 YAML はそのままで、チップ列は出ない。
