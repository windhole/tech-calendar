# 0019. 開催地は 13 種のうち 1 つ

Date: 2026-09-06
Status: Accepted
Supersedes: [0018](0018-event-tags.md)

## Context

カレンダーとリストを開催エリアで絞りたい。ADR-0018 は自由語の複数タグと OR 絞り込みにした。実際に必要なのは開催地であり、値は決まった 13 種のどれか 1 つだけである。汎用タグは後で別途足す可能性はあるが、いまの項目としては扱わない。

## Decision

- イベントは任意の `region`（開催地）を 1 つ持つ。無いときは省略。値は次のいずれか。
  オンライン、北海道、東北、関東、東京、甲信越、中部、北陸、関西、中国、四国、九州、沖縄
- YAML は `region: 東京`。csv2yaml は CSV の `開催地` 列を 1 値として読む（古い `tag` 列も読む）。先頭の `#` は除く。空ならキーを出さない。13 種以外はエラーで止める。
- チップはデータに出てくる開催地だけを出し、「すべて」の右に上の順で並べる。絞り込みは複数選択の OR。選択は `?region=` に載せる。

## Consequences

- 会場の自由記述 `location` と、絞り込み用の開催地 `region` が分かれる。
- 1 イベントが「東京」と「関東」の両方にはならない。
- 汎用タグ用の配列は持たない。
