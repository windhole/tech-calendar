# 0008. 「今日」でイベントと祝日 YAML を再取得する

Date: 2026-09-03
Status: Accepted

## Context

イベントと祝日は起動時（祝日は表示中の年が変わったとき）に `fetch` する。YAML を直しても、開いているタブは古いまま。手元で `public/` を更新したあと、画面を閉じずに取り込みたい。

## Decision

- 「今日」をクリックしたら、月を今日に戻すだけでなく `events.yaml` と、表示中の年の祝日 YAML を取り直す。
- 再取得ではブラウザ／CDN のキャッシュを避ける（`cache: 'no-store'` とクエリ `?t=`）。初回読み込みはこれまでどおり。
- 祝日のメモリキャッシュは再取得前に捨てる。画面全体を「読み込み中」には戻さない。

## Consequences

- ローカルでは YAML を保存して「今日」で反映できる。
- GitHub Pages では、デプロイ済みの `dist/` が対象。未 push の編集は公開サイトには出ない。
- 「今日」以外の月送りでは、祝日は従来どおりメモリキャッシュを使う。
